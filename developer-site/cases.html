ДЛ Коннект — интеграция «Деловых Линий» с inSales и amoCRM

SaaS-сервис для интернет-магазинов и отделов продаж: расчёт стоимости доставки, оформление заявок и синхронизация статусов «Деловых Линий» — прямо в привычном интерфейсе. Сейчас ищу первых пользователей, чтобы обкатать сервис в реальных рабочих процессах.

Задача

Магазины и отделы продаж, которые возят «Деловыми Линиями», вели заявки руками: менеджер копировал адреса из заказа в личный кабинет перевозчика, ошибался в габаритах, забывал обновить статус клиенту. На каждый заказ — минуты ручной работы и место для ошибки.

Нужен был сервис, который подключается за один вечер по инструкции — без программиста на стороне клиента.

Решение

Полный цикл в одиночку: спроектировал архитектуру, написал бэкенд, развернул инфраструктуру, оформил юридическую часть, сделал лендинг для прямых продаж.

Расширение: тот же движок — виджет для amoCRM

Один и тот же расчёт доставки и синхронизация статусов теперь доступны и внутри amoCRM: виджет встраивается прямо в карточку сделки, использует OAuth2-авторизацию amoCRM и опубликован в официальном маркетплейсе amoCRM — там, в отличие от inSales, разработчик не платит комиссию с продаж.

Технически это отдельный AMD-модуль поверх общего бэкенда — не копия кода под другую платформу, а второй фронт к той же системе.

Инженерия

  • Бэкенд на PHP 8.4, MariaDB
  • Вебхуки с проверкой подписи
  • Rate limiting, CSP-заголовки
  • Кэширование сессий API с инвалидацией
  • amoCRM-виджет: AMD-модули, OAuth2
  • Деплой и администрирование VPS

Продукт

  • Лендинг для прямых продаж
  • Гайд по настройке
  • Аналитика Matomo (self-hosted)
  • UX админ-панели настроек

Право

  • Соответствие 152-ФЗ
  • Политика обработки ПДн
  • Уведомление Роскомнадзора
  • Self-hosted шрифты и скрипты
